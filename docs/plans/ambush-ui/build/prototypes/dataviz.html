Perch · specimen

Data-visualization plates

Six primitives — VIZ-1 ConcentrationCurve, VIZ-2 HostHeat, VIZ-3 KillChainGraph, VIZ-4 IncidentTimeline, VIZ-5 ContainmentLeaseTimer, VIZ-6 RateSparkline — in every state, in both themes, in both data regimes. 18-DATAVIZ.md is the spec; this page is the specimen.

Numbers are computed on load from the same closed form the runtime evaluates — strength(t) = confidence · 0.5^((t − timestamp) / decay_half_life) — over the canonical scenario in fixtures/perch-demo-fixture.json. The five concentration checkpoints this page draws reproduce that file to six decimal places; viz/dataviz-fixture.mjs asserts it and fails loudly if either side moves.
