Perch The Record

Drawn from adjudication and the permanent record — the docket, the exhibit, the chain of custody, the seal, and the ruled line where a name goes. A verdict here is typed, signed and permanent, so the console is not a dashboard of cards: it is a bench, and the thing on it is a document. The neutral system is two materials and no third. The console is graphite — R = G = B on every step, both themes, no hue at all. The record is warm stock, and it is the only coloured material in the room. Which thing is the document is answered before a label is read.

The signature · the one thing this direction is remembered by

Every record ends in two ruled lines: the record's own, and yours. The first is hatched, and it stays hatched — ambush:hold:v1 carries no Ed25519 signature in Ambush under any condition, so the document reaches your bench unsigned and says so in its shape. The second is empty, and waiting. The grant is not a button: it is a blank signature line under the tallest field in the system, and arming rules the page — the field goes from bare stock to ruled in your own ink, so the difference between armed and unarmed is a quantity of ink you cannot miss with the colour turned off. Refuse is a stamp: one motion. A signature is two.

Four chromatic values · one job each · absence gets none
wax
The seal, and the only hue that ever means this can hurt. It is a mark, never a word: it is always a fill or a rule, never text, so it never has to fight a contrast floor.
indelible
Copying-pencil violet — the operator's own hand. Nothing the machine writes is ever this colour, and arming a grant rules the page in it.
adversary
The manila exhibit tab: a string the attacker wrote, quoted and never executed. It is drawn as a tab, not a hatch — hatch means absence here and nothing else.
custody
Verdigris on an old seal: a check that actually ran and agreed.

The adversary frame

Manila-tabbed values are written by the adversary. They render as inert plain text — no markdown, no autolinking, no mention resolution — with control, zero-width and bidi codepoints escaped to a visible form before they reach the DOM, and nothing here is ever passed to an agent as instruction. Enum and integer fields carry no tab, which is what makes the tab mean something.

The tab is a tab and not a hatch on purpose. In this system hatching means absence and only absence, so an attacker's string and a missing field can never be confused for one another at a glance.

Verification tier, without colour

An unsigned record differs from a signed one in shape: a hatched stamp in the margin, a hatched rule where the signature would be, and the words. When a card does carry an attestation the same rule takes ink and the stamp is solid. Nothing about the tier is carried by hue, so it survives a monochrome monitor and every form of colour blindness intact.

Four of Perch's eleven card types carry no signature at all. This system draws that as a hole in the page rather than as a quiet grey label.
