<objective>
Implement COMPOSE-05 so live canary and promotion flows can safely target one baseline strategy while runtime detection is using a CompositeDetector.

Purpose: Remove rollout ambiguity in multi-strategy mode and prevent canary or promotion from silently comparing against the wrong baseline strategy.
Output: Optional rollout-scope config, validation, shared detector factory reuse, scoped canary/promotion behavior, and tests that lock the handoff behavior.
</objective>
