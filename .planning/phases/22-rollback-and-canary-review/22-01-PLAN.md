# Phase 22 Plan 01: Rollback And Canary Review

<objective>
Turn rollback and canary review into durable operator workflows with explicit automatic safety gates, manual controls, and stable review artifacts.
</objective>

<read_first>
- .planning/phases/22-rollback-and-canary-review/22-CONTEXT.md
- .planning/phases/21-bounded-canary-execution-and-metrics/21-01-PLAN.md
- crates/swarm-runtime/src/canary.rs
- crates/swarm-runtime/src/bin/swarmctl.rs
- docs/EVOLUTION.md
</read_first>

<tasks>
<task number="1" type="auto">
<description>Add automatic rollback thresholds and persisted rollback history.</description>
<acceptance_criteria>
- Canary runs move to a rolled-back state when configured thresholds or budgets fail.
- Rollback history records timestamp, reason, and reverted baseline strategy.
- Tests cover at least one automatic rollback path.
</acceptance_criteria>
</task>

<task number="2" type="auto">
<description>Add manual halt and manual rollback operator actions.</description>
<acceptance_criteria>
- Operators can halt or roll back an active canary via `swarmctl`.
- Manual actions preserve the supplied reason and affected slot.
- Completed or rolled-back canaries can be reloaded by stable ID.
</acceptance_criteria>
</task>

<task number="3" type="auto">
<description>Emit the final canary review surface and document the lifecycle.</description>
<acceptance_criteria>
- The canary artifact links verification, shadow, and canary evidence.
- The artifact carries a ready-for-promotion or blocked recommendation.
- Docs explain start -> ingest -> result -> rollback workflow.
</acceptance_criteria>
</task>
</tasks>

<verification>
- cargo test -p swarm-runtime canary --quiet
- cargo fmt --all --check
- cargo clippy --workspace -- -D warnings
</verification>

<success_criteria>
- Bounded canary execution has real automatic and manual rollback behavior.
- Operators can inspect rollback history and final canary recommendations through stable IDs.
- The milestone is ready for audit and archival without introducing production promotion or consensus.
</success_criteria>
