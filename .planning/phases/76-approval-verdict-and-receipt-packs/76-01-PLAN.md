Create `crates/swarm-runtime/src/approval.rs` with the following structure:

**Error enum:**
- `ApprovalError` with variants: `Store(String)`, `Io(std::io::Error)`, `Json(serde_json::Error)`, `Crypto(swarm_crypto::CryptoError)`, `InvalidLedger(String)`, `MissingApprovalSet(String)`, `SigningKeyMissing(String)`

**Verdict types:**
- `ApprovalVerdictStatus` enum: `Approved`, `NotApproved`
- `ApprovalVerdictReport` struct with fields: `verdict_id: String`, `approval_set_id: String`, `ledger_id: String`, `status: ApprovalVerdictStatus`, `approve_count: u32`, `reject_count: u32`, `threshold_required: String` (human-readable threshold description), `eligible_count: u32`, `missing_voters: Vec<String>`, `evaluated_at: String`
- `ApprovalVerdictRecord` struct wrapping the report plus `created_at: String` and serialized JSON bytes for storage
- `ApprovalVerdictLookup` and `ApprovalVerdictList` structs

**Pure verdict function:**
- `pub fn evaluate_verdict(approval_set: &ApprovalSet, ledger: &ApprovalLedger) -> Result<ApprovalVerdictReport, ApprovalError>`
- This function MUST be a pure function: no I/O, no timestamps (caller provides), no randomness
- Accept an `evaluated_at: &str` parameter for the timestamp
- Generate `verdict_id` deterministically from `sha256(canonical_json(approval_set_id + ledger_id + evaluated_at))`
- Count approvals and rejections from ledger entries where voter is in eligible_voters
- Evaluate threshold: Count(n) requires approve_count >= n, Majority requires approve_count > eligible_count/2, Unanimous requires approve_count == eligible_count and reject_count == 0
- Compute missing_voters as eligible voters who have no entry in the ledger

**Receipt pack types:**
- `ApprovalReceiptPackReport` struct with fields: `pack_id: String`, `approval_set: serde_json::Value` (serialized approval set), `ledger_entries: Vec<serde_json::Value>` (serialized entries), `verdict: serde_json::Value` (serialized verdict), `audit_refs: Vec<String>`, `content_hash: String` (SHA-256 of canonical JSON of pack content), `signature: swarm_crypto::DetachedSignature`, `created_at: String`
- `ApprovalReceiptPackRecord` struct for storage
- `ApprovalReceiptPackLookup` and `ApprovalReceiptPackList` structs

**Receipt pack construction:**
- `pub fn build_receipt_pack(approval_set: &ApprovalSet, ledger: &ApprovalLedger, verdict: &ApprovalVerdictReport, audit_refs: Vec<String>, signer: &Ed25519Signer, created_at: &str) -> Result<ApprovalReceiptPackReport, ApprovalError>`
- Serialize approval_set, ledger entries, and verdict to serde_json::Value
- Assemble a content object with all four fields (set, entries, verdict, audit_refs)
- Compute canonical JSON bytes of the content object
- SHA-256 hash the canonical bytes for `content_hash`
- Sign the canonical bytes with the Ed25519Signer
- Generate `pack_id` from `sha256(content_hash + signer.key_id())`

**Receipt pack verification:**
- `pub fn verify_receipt_pack(pack: &ApprovalReceiptPackReport) -> Result<(), ApprovalError>`
- Reconstruct the content object from pack fields
- Compute canonical JSON bytes
- Verify content_hash matches SHA-256 of canonical bytes
- Call `swarm_crypto::verify_detached_signature` with canonical bytes and pack.signature

**File stores:**
- `FileApprovalVerdictStore` following the pattern in `governance_prep.rs`: `open(path)`, `persist(record)`, `load(id)`, `list()`
- `FileApprovalReceiptPackStore` same pattern
- Store files as `{id}.json` in the respective directories

**Harness:**
- `DefaultApprovalHarness` struct holding both stores plus paths to Phase 75 stores (approval sets and ledgers)
- `from_path(config, verdict_dir, receipt_pack_dir, approval_set_dir, ledger_dir) -> Result`
- `create_verdict(approval_set_id, ledger_id) -> Result<ApprovalVerdictLookup>`: loads approval set and ledger from Phase 75 stores, calls evaluate_verdict, persists
- `load_verdict(verdict_id) -> Result<ApprovalVerdictLookup>`
- `list_verdicts() -> Result<ApprovalVerdictList>`
- `export_receipt_pack(verdict_id, signer_id, signing_key_env) -> Result<ApprovalReceiptPackLookup>`: loads verdict + its source approval set and ledger, builds receipt pack, persists
- `load_receipt_pack(pack_id) -> Result<ApprovalReceiptPackLookup>`
- `list_receipt_packs() -> Result<ApprovalReceiptPackList>`
- `verify_receipt_pack(pack_id) -> Result<bool>`: loads pack from store, calls verify_receipt_pack

**Render functions:**
- `render_approval_verdict(report) -> String`: table showing verdict status, counts, threshold, missing voters
- `render_approval_verdict_list(list) -> String`: summary table of all verdicts
- `render_approval_receipt_pack(report) -> String`: table showing pack ID, content hash, signature metadata, verdict summary
- `render_approval_receipt_pack_list(list) -> String`: summary table of all packs

**Register the module** in `crates/swarm-runtime/src/lib.rs` by adding `pub mod approval;` to the module list.
