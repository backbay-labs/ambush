<objective>
Implement the restart-safe herd-memory lifecycle: durable refusal/quarantine/contradiction state, atomic accepted imports, revocation/expiry/deletion, and tombstone-first garbage collection.

Purpose: a correct envelope is not enough if accepted state, indexes, heads, or refusal reasons can diverge across a crash. Lifecycle state must be authoritative and non-actionable after expiry, revocation, quarantine, contradiction, or deletion.
Output: memory and local-file stores with identical logical semantics, atomic generations, durable refusal reasons, and complete restart/fault/GC tests.
</objective>

Lifecycle queries must expose only records whose status is `Accepted`, unexpired, non-revoked, non-quarantined, non-contradicted-for-action, and non-tombstoned. Refusal, quarantine, contradiction, and tombstone records are review/audit state, never retrieval authority.

HerdMemoryContextKey and HerdMemoryQuery are owned by swarm-spine and contain
only bounded canonical digests/IDs, epoch, and ordered typed sets. They must not
import swarm-runtime or reference runtime graph/strategy structs.
HerdMemoryStore::actionable_matches and contradictions accept this
spine-neutral query. Plan 05 owns the richer runtime HerdMemoryContext and
converts it field-by-field to HerdMemoryQuery; no spine trait accepts a runtime
type.
