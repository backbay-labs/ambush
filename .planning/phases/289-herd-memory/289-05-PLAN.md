<import_boundary_contract>
Run `bash tools/check-herd-memory-upstreams.sh --run -- bash -c '<task command>'`
before importer work. The only public wire entry point is
`HerdMemoryImporter::deserialize_and_import(&[u8])`. It applies a
bounded `MAX_ENVELOPE_BYTES` check before parsing, uses a duplicate-key-aware
canonical decoder with `deny_unknown_fields`, rejects noncanonical bytes and
trailing data, enforces per-field/collection limits, and writes only a typed
refusal digest/reason to durable lifecycle state on failure. The importer
forwards only the bounded raw bytes to Plan 03's
`HerdMemoryLifecycleHandle::import_untrusted_bytes`; the envelope, decoder
token, verifier, refusal mutator, and locked CAS remain private to the handle.
There is no public typed-envelope, candidate, ticket, or verified-value
constructor. Decode failure itself enters the handle-owned durable refusal CAS,
so a crash or retry cannot turn malformed bytes into accepted/index state. Tests
mutate unknown keys, duplicate keys, key order/whitespace, trailing bytes,
over-limit bytes, invalid UTF-8, and truncated signatures and assert durable
refusal plus zero accepted/index state.
</import_boundary_contract>

<interfaces>
The lifecycle store exposes the production `HerdMemoryStore` trait and typed
state/query methods owned by swarm-spine. The production importer owns the
concrete configured file store through the single lifecycle handle.
`FileHerdMemoryStore`, its constructor, mutators, and direct state readers are
crate-private to swarm-spine. The in-memory backend is declared and tested only
inside swarm-spine's `#[cfg(test)] mod tests`; no runtime constructor or
cross-crate integration test takes either type, so neither can become a
production injection seam:
```rust
pub struct HerdMemoryImporter {
    lifecycle: HerdMemoryLifecycleHandle, // private, config-bound sole authority
    factory: HerdMemoryRuntimeFactory,
}
impl HerdMemoryImporter {
    pub fn from_config(config: &HerdMemoryConfig) -> Result<Self, ImporterError>;
    pub fn deserialize_and_import(&mut self, bytes: &[u8]) -> Result<ImportStatus, StoreError>;
}
```

The Plan 03 handoff is one raw-byte method only:
```rust
impl HerdMemoryLifecycleHandle {
    pub fn import_untrusted_bytes(&mut self, bytes: &[u8])
        -> Result<ImportStatus, StoreError>;
    #[cfg(test)]
    pub(crate) fn import_untrusted_bytes_at(&mut self, bytes: &[u8], now_ms: u64)
        -> Result<ImportStatus, StoreError>;
}
```
The lifecycle handle owns production time and the durable refusal/acceptance
CAS. The test-only `*_at` method is available only to spine unit tests through
the test clock; no production caller can inject time, a store, a registry, a
resolver, a candidate, or a verifier result.

The store trait and HerdMemoryQuery/HerdMemoryContextKey are owned by
swarm-spine; the runtime HerdMemoryContext is runtime-owned and is never a
spine field or trait parameter. HerdMemoryContext::to_store_query() performs
the bounded field-by-field conversion and recomputes canonical digest ordering.
This ownership rule is tested with a dependency/source scan that rejects any
swarm-spine -> swarm-runtime edge or runtime type in the spine store module.

The advisory adapter must return a data-only hint:
```rust
pub struct TaskOrderHint {
    pub delta_basis_points: u16,
    pub matched_memory_ids: BTreeSet<Digest64>,
    pub corroboration_digest: Digest64,
}
```
`Digest64` is the shared typed lower-case 64-hex wrapper; no `String` or
display helper is accepted at this boundary. It must not return a policy
verdict, receipt, approval, capability lease, action, dispatcher request, or
confidence replacement.

The trust handoff is private to the Plan 03 coordinator:
```rust
pub(crate) struct HerdMemoryImportTicket { /* non-serializable single-use reservation */ }
```
`HerdMemoryImporter::from_config(config)` must validate the config, construct
the `HerdMemoryRuntimeFactory`, and obtain exactly one
`HerdMemoryLifecycleHandle::from_config`; that handle opens the configured
durable `FileHerdMemoryStore` and `HerdMemoryConfig.issuer_registry_path` and
owns the lock/registry/store for its entire production lifetime. No production
constructor accepts `&mut dyn HerdMemoryStore`, a memory backend, a custom
store, a caller signer, or a custom resolver. `MemoryHerdMemoryStore` remains
`#[cfg(test)] pub(crate)` only inside the spine store's own unit-test module;
runtime unit tests use a private temporary config harness, and external
integration tests use only the public `from_config` path; they cannot name or
construct `FileHerdMemoryStore`. There is no production test feature, cross-crate memory-store type, or
test-only importer constructor to link into a normal build.
Missing/insecure key-root/provider/store custody is a typed error, never a
request to create a process-local/test resolver. No runtime path may call a
free-standing verifier, pass a bare typed envelope or verified value to
storage, or bypass the candidate handoff/lock authority.
