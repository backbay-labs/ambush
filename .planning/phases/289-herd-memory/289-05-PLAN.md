<interfaces>
The lifecycle store exposes only typed state/query methods:
The trait shown here is defined and implemented by Plan 03 in swarm-spine;
this plan only calls it through its public spine export and never redefines a
runtime-backed store trait.
```rust
pub trait HerdMemoryStore {
    fn import_verified(&mut self, envelope: VerifiedHerdMemory) -> Result<ImportStatus, StoreError>;
    fn actionable_matches(&self, query: &swarm_spine::HerdMemoryQuery) -> Vec<StoredHerdMemory>;
    fn contradictions(&self, query: &swarm_spine::HerdMemoryQuery) -> Vec<ContradictionRecord>;
}
```

The store trait and HerdMemoryQuery/HerdMemoryContextKey are owned by
swarm-spine; the runtime HerdMemoryContext is runtime-owned and is never a
spine field or trait parameter. HerdMemoryContext::to_store_query() performs
the bounded field-by-field conversion and recomputes canonical digest ordering.
This ownership rule is tested with a dependency/source scan that rejects any
swarm-spine -> swarm-runtime edge or runtime type in the spine store module.

The advisory adapter must return a data-only hint:
```rust
pub struct TaskOrderHint { pub delta_basis_points: u16, pub matched_memory_ids: BTreeSet<String>, pub corroboration_digest: String }
```
It must not return a policy verdict, receipt, approval, capability lease, action, dispatcher request, or confidence replacement.

The trust handoff is the explicit Plan 02 type:
```rust
pub struct VerifiedHerdMemory { /* verified envelope/body hash, registry generation, verified epoch */ }
```
`HerdMemoryImporter::from_config(config: &HerdMemoryConfig, store: &mut dyn HerdMemoryStore)` must open `HerdMemoryConfig.issuer_registry_path`, construct the repository-owned `FileOpaqueKeyProvider` from the validated `HerdMemoryConfig.opaque_key_root` through `HerdMemoryRuntimeFactory::from_config`, bind tenant/local receiver/export namespace and the configured opaque-key resolver reference, and accept serialized bytes only through `verify_import -> VerifiedHerdMemory`. Missing/insecure key-root/provider construction is a typed error, never a request to create a process-local/test resolver; any fixture-provider constructor is `#[cfg(test)]` only.
</interfaces>
