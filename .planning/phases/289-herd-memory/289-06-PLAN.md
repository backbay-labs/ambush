second JSON/CBOR/serde shape or short-form field aliases are permitted:

```rust
pub(crate) const REQUEST_FIELDS: &[&str] = &[

    "freeze_receipt_digest", "candidate_lineage_digest", "request_nonce", "withheld_version",

```

Each list is the sole serialization order. Canonical bytes are UTF-8,
duplicate-key rejecting, sorted only according to the declared list (not a
generic map), with integers encoded as decimal integers and typed digests as
lowercase 64-hex. A receipt digest excludes only `receipt_digest` and
`root_signature`; a request digest excludes only `request_digest` and
`evaluator_signature`; a response digest excludes only `response_digest` and
`evaluator_signature`. No digest is accepted if moved, duplicated, nested,
renamed, self-included, or accompanied by an unknown field. The self-exclusion
rule is tested independently for every field in every message, including all
three schema/domain names and every issuance linkage field.

`issuance_id` is a fresh typed Digest64 issued by the evaluator process. The
private capability stores it only as an in-memory linkage field and has no
serialization implementation; the provider copies that value into the signed
receipt/request/response wire fields in the canonical order above. Thus the
signed wire issuance ID is authenticated transport linkage, not a serialized
capability. It is never emitted in `Debug`, logged, used as a path, or accepted
without the matching process nonce, candidate-freeze receipt, and receipt.
Private withheld tuple/record values remain private to the evaluator process;
their tactic/technique/primitive/order/timing values and per-case digests
cannot be constructed by candidate code or appear in any IPC message. Tests
mutate every name, field, order, self-digest, issuance ID,
process nonce, signature byte, unknown/duplicate key, and private-record escape
attempt and require a typed refusal.
</canonical_evaluator_ipc_schema>

The evaluator boundary is a concrete provider-owned Rust capability, not a
serialized flag or a path string:
```rust

    receipt_digest: Digest64,
    candidate_lineage_digest: Digest64, // exact ArenaLineage::source_digest
    issuance_id: Digest64,
    opaque_handle: Digest64,
    evaluator_process_nonce: Digest64,
    one_shot: std::rc::Rc<std::cell::Cell<bool>>,
    // private evaluator handle; no path, key bytes, or manifest contents
}
pub(crate) struct PostFreezeEvaluatorProvider { /* private evaluator resolver */ }
impl PostFreezeEvaluatorProvider {
    pub(crate) fn issue_after_freeze(
        &self,
        receipt: SignedFreezeReceipt,
    ) -> Result<PostFreezeEvaluatorCapability, EvaluatorRefusal>;
    pub(crate) fn evaluate_after_freeze(

```
The capability has no `Clone`, `Copy`, `Debug`, `Serialize`, or `Deserialize`
implementation, its constructor is private to the provider module, and the
`Rc<Cell<bool>>` one-shot marker makes reuse fail closed. Candidate/importer
modules receive neither provider nor capability types. The evaluator module is
crate-private and is not re-exported from `crates/swarm-runtime/src/lib.rs`;
only the benchmark/evaluator bridge can hold the opaque crate-private handle.
The only cross-process boundary is the signed IPC request/response, and only
a signed freeze receipt binding the public/upstream pins and candidate lineage
can issue the handle.

The evaluator's private withheld tuple/record aggregate and its
case/fingerprint/content fields are implementation details of the evaluator
process and are never a public Rust type, return value, export, serde DTO,
debug value, or IPC payload. The only
candidate-visible evaluator boundary is canonical authenticated
`SignedEvaluatorRequest` -> `SignedEvaluatorResponse`; the provider's
`evaluate_after_freeze` method is the sole provider operation (crate-private)
and returns only
the signed aggregate response. The evaluator process keeps withheld records
in-process and destroys its private aggregate after the one-shot response.
There is no public withheld-record aggregate, `pub open_withheld`, record
iterator, path resolver, or caller-provided evaluator provider. Tests
compile-scan the
public API and mutate a forged record/response, case ID, path, fingerprint,
and resolver output; each is refused and no withheld field appears in the
candidate report.

The provider issues a fresh `issuance_id` and signed freeze receipt per
evaluator process after all in-sample export/calibration is frozen. The ID is
unique, private, non-serializable, and bound to process nonce, lineage, public
and upstream digests, schema/domain/epoch, and evaluator result digest. A used,
cross-process, replayed, logged, or mismatched issuance ID is refused.
