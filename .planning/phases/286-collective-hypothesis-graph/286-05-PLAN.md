<ownership_boundary>
Plan 04 remains the sole owner of the durable task ledger, lease/fence
transitions, terminal outbox, and the `accept_terminal_once` CAS. Plan 03B
remains the sole owner of the graph-store protocol and StrategyMemory file/
memory persistence. Plan 02B remains the owner of immutable witness admission
and graph-record signer construction. Plan 05 only adds the Stalker/Weaver
role adapters and the runtime memory-priority projection; it must consume
those contracts and must not add a task map, store facade, lease implementation,
outbox, signer, or second memory ledger.

The existing `queued_hunts`, `published_hunts`, and `correlated_hunts`
process-local `HashSet`s are retained only for the pre-graph/legacy agent
behavior and compatibility tests. They may be read or written only when the
optional durable graph adapter is absent. When the graph path is enabled, it
must not consult, mutate, or treat any of those sets as duplicate suppression,
task ownership, evidence-work admission, or publication state. An absent
adapter therefore selects an explicitly legacy path that emits no trusted
graph task result; it is never an implicit in-memory fallback for graph work.

`collective_hypothesis_graph.rs` is a shared integration fixture. Plan 04
owns its hypothesis/store/outbox assertions, Plan 02B owns admission and
scheduler assertions, and Plan 05 appends only the named role-allocation,
restart/fence, duplicate-work, and memory-priority tests below. Existing
tests and helpers are additive dependencies, not overlapping ownership.
</ownership_boundary>

<interfaces>
The agents receive an optional injected durable adapter (a test double may
implement the same interface) with operations equivalent to:

```rust
trait DurableGraphTaskAdapter {
    fn claim(&self, request: &TaskClaimRequest, now: GraphLogicalTime)
        -> Result<TaskClaim, GraphAdmissionError>;
    fn renew(&self, claim: &TaskClaim, now: GraphLogicalTime)
        -> Result<TaskClaim, GraphAdmissionError>;
    fn reclaim_expired(&self, task_id: &TaskId, now: GraphLogicalTime)
        -> Result<TaskClaim, GraphAdmissionError>;
    fn accept_terminal_once(
        &self,
        claim: &TaskClaim,
        publication: TaskTerminalOutboxEntry,
    ) -> Result<(), GraphAdmissionError>;
}
```

This is an agent-facing injection seam, not a second ledger: its concrete
implementation delegates to Plan 04's public claim/lease/reclaim and
`accept_terminal_once` operations over the injected
`HypothesisGraphStore`. A claim refusal is returned before evidence work; a
successful terminal call is the one CAS that admits the terminal task,
evidence, decision, and optional memory into the outbox. The adapter carries
the immutable Plan 02 `WitnessAdmission` snapshot and uses
`KeypairGraphRecordSigner::with_admission`; callers cannot supply an
unadmitted allowlist or a role/scoped alias as authority.
</interfaces>
