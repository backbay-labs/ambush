    **SecretLeakConfig struct**: `enabled: bool` (default true), `redact: bool` (default true), `severity_threshold: Severity` (default Error), `patterns: Vec<SecretPattern>` (default high-value patterns).

    Default patterns (high-value subset from upstream):
    - `aws_access_key`: `r"AKIA[0-9A-Z]{16}"`
    - `aws_secret_key`: `r#"(?i)aws[_\-]?secret[_\-]?access[_\-]?key['"]?\s*[:=]\s*['"]?[A-Za-z0-9/+=]{40}"#`
    - `github_token`: `r"gh[ps]_[A-Za-z0-9]{36}"`
    - `github_pat`: `r"github_pat_[A-Za-z0-9]{22}_[A-Za-z0-9]{59}"`
    - `openai_key`: `r"sk-[A-Za-z0-9]{48}"`
    - `anthropic_key`: `r"sk-ant-[A-Za-z0-9\-]{95}"`
    - `private_key`: `r"-----BEGIN\s+(RSA\s+)?PRIVATE\s+KEY-----"`
    - `npm_token`: `r"npm_[A-Za-z0-9]{36}"`
    - `slack_token`: `r"xox[baprs]-[0-9]{10,13}-[0-9]{10,13}[a-zA-Z0-9-]*"`
    - `stripe_secret_key`: `r"sk_live_[A-Za-z0-9]{24,}"`
    - `generic_api_key`: `r#"(?i)(api[_\-]?key|apikey)[\x27"]?\s*[:=]\s*[\x27"]?[A-Za-z0-9]{32,}"#` (Warning severity)
    - `generic_secret`: `r#"(?i)(secret|password|passwd|pwd)['"]?\s*[:=]\s*['"]?[A-Za-z0-9!@#$%^&*]{8,}"#` (Warning severity)

    **Compiled state**: `CompiledPattern` struct (name, regex, severity) built from config at construction time.

    **SecretLeakGuard struct**: `name: String`, `enabled: bool`, `redact: bool`, `severity_threshold: Severity`, `patterns: Vec<CompiledPattern>`.

    **scan(&self, content: &[u8]) -> Vec<SecretMatch>**: Convert to UTF-8, iterate patterns, collect matches. `SecretMatch` has: `pattern_name`, `severity`, `offset`, `length`, `redacted`.

    **Redaction**: `mask_value(s)` shows first 4 and last 4 chars, masks middle with `*`. If string <= 8 chars, mask entirely.

    **severity_rank** helper: Info=0, Warning=1, Error=2, Critical=3. Used to compare against threshold.

    **Guard trait implementation**:
    - `name()` returns "secret_leak"
    - `handles()` returns true for `FileWrite` and `ResponseAction` (secrets can appear in response action arguments). Return false for `FileAccess`, `ShellCommand`, `NetworkEgress`.
    - `check()`: For `FileWrite(_, content)`, scan the content bytes. For `ResponseAction(action)`, serialize the action to JSON string and scan those bytes. If any match has severity >= threshold, return `GuardResult::block` with the highest-severity match details. Otherwise return allow.

    Update `src/lib.rs` to replace the stub re-export with real re-exports: `pub use secret_leak::{SecretLeakGuard, SecretLeakConfig, SecretPattern};`
