<interfaces>
Packet lineage contains the Runtime-owned `ArenaSynthesisInput`, including its
`PairReportView` and `ArenaArtifactView`, plus immutable source references and
digests for the Arena-owned `BlueOutcome`, `ArenaIngestResult`,
`Phase286InvestigationCapture`, `ArenaArtifactStore` CAS/fence record,
concrete `PairReport`, and `SignedBlueLearnedState`. The packet never embeds
those concrete Arena records or re-runs their operations; it binds both
candidate/control state digests, partition/corpus/source/schema IDs, response
preview/rollback, and all controls.
The packet store reuses Arena's
`compare_and_append(stream, expected_generation,
expected_predecessor_digest, fencing_token, signed_payload)` semantics and
`SignedStateEnvelope::sign`/`verify(SignedStateExpectation)`. The expectation
checks kind, signer, stream, sequence, generation, predecessor, fencing token,
schema, payload/content digest, and signature on every load and handoff.

Every packet and handoff also carries one present, nonempty
`EvolutionSolverInvariantArtifact` from `evolution/types.rs`. Its canonical
JSON bytes, computed canonical SHA-256 digest, existing `attestation_sha256`,
and `EvolutionSolverProofStatus::Proved` status are bound into the signed
packet and signed synthesis report; review/verification artifacts bind the same
digest and attestation. Handoff recomputes the artifact
bytes/digest and attestation immediately before canary and again before
operator/quorum review; absent, disabled, malformed, digest-mismatched, stale,
or non-`Proved` artifacts fail closed and cannot be replaced by an assurance
configuration flag. `invariant_name`, `solver`, `compiled_query_sha256`,
`attestation_sha256`, and status must be nonempty/valid; `rlimit` is the
deterministic solver budget and `duration_ms` is observation-only and never a
verdict input. Define the bound `canonical_solver_bytes` projection before
hashing so `duration_ms` (and any explicitly observational wall-clock field)
is excluded from the solver digest; fixed status/query/attestation/budget and
counterexample fields remain bound.

The implementation-tree input is a stable explicit allowlist: `crates/swarm-runtime/src/lib.rs`,
`crates/swarm-runtime/src/synthesis/**`,
`crates/swarm-runtime/src/mutation/{types.rs,autonomous.rs,fitness.rs,tests_core.rs,tests_autonomous.rs}`,
`crates/swarm-runtime/src/service/{runtime_service.rs,tests_preview.rs}`,
`crates/swarm-runtime/tests/{synthesis_contract.rs,negative_synthesis_authority_boundary.rs,synthesis_integration.rs,synthesis_response.rs,synthesis_evaluation.rs,synthesis_controls.rs,synthesis_handoff.rs,synthesis_phase_gate.rs}`,
`crates/swarm-arena/src/{lib.rs,synthesis_adapter.rs}`,
`crates/swarm-arena/tests/{synthesis_adapter.rs,synthesis_evaluation_bridge.rs,synthesis_controls_bridge.rs}`,
the four lane files plus `manifest.yaml` under `scenarios/autonomous-detector-response-synthesis/`,
and the five owned Phase 288 gate/parser sources under `tools/` (plus a Cargo
manifest/lock only when explicitly listed by a plan). The helper rejects
symlinks, duplicate/out-of-scope paths, `.git`, `target`, caches, worktrees,
generated/self-referential review/verification/validation/summary documents,
`artifacts/synthesis/**`, and run roots. It emits sorted path/blob digests as
`tree_digest`/`combined_tree_digest` from that same frozen allowlist plus a
separately checked `head_oid`. The immutable `phase287_evidence_digest` is
`SHA256(canonical_json_bytes(artifacts/phase287/final-gate/arena-report.json) ||
"\n" || canonical_json_bytes(artifacts/phase287/final-gate/arena-lineage.json)
|| "\n" ||
canonical_json_bytes(artifacts/phase287/final-gate/final-gate-evidence.json))`;
the Phase 287 config-inventory/parser commands are rerun independently, while
these exact retained bytes are the digest input and are never included in the
implementation digest.
</interfaces>
