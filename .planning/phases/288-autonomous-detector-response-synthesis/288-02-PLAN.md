`crates/swarm-runtime/src/synthesis/arena_input.rs` is the only owner of the
Runtime DTOs `ArenaSynthesisInput`, `PairReportView`, and `ArenaArtifactView`.
`Phase287ArenaSynthesisAdapter` is the only producer: Blue runs, CAS/fencing,
and concrete `PairReport` stay in `swarm-arena`; Runtime receives views and
never imports or executes those Arena types. The adapter validates the full
signed envelope and maps all required fields to typed views before the one-way
handoff.

The injected result is constructed only by
`swarm_ingest_runtime::ingest::ArenaIngestResult::from_injected_runtime(
normalized_event, normalized_event_digest, findings, phase286_capture,
no_action, safety) -> Result<ArenaIngestResult, String>`; the adapter must not
construct a parallel result or copy a replay side channel.

The exact source/normalization seam is
`FixtureTarget::normalize_event(&FixtureEvent, GraphLogicalTime) ->
Result<TelemetryEvent, FixtureError>` followed by
`pub async fn IngestState::process_bridge_event_at<D,P,E>(&self,
TelemetryEvent, &dyn GraphClock, &ArenaDetectionStrategyAdapter<D>,
&ConfiguredRuntimeStack<P,E,Phase286StrategyBridge>) ->
Result<ArenaIngestResult, String>` with the Phase 287 bounds
`D: DetectionStrategy, P: ApprovalGate, E: ResponseExecutor`. Construct the concrete
`ArenaDetectionStrategyAdapter<D>::new(inner)` around the admitted detector;
do not invent a provider trait or a generic replay seam. The call uses the
six-argument
`ConfiguredRuntimeStack::from_graph_components(config, policy, response, bridge,
authority, signer_binding)` composition. The adapter must preserve the complete
`ArenaIngestResult` (`normalized_event_digest`, findings, `phase286_capture`,
`no_action`, safety), the one `Phase286InvestigationCapture.replay` if
actionable, and the `DryRunTraversalReceipt` if present. `red_projection()` is
Red-only and is never used as detector-synthesis input. The generic
`DefaultReplayHarness` is not an Arena evidence source.
</interfaces>
