<interfaces>
`tools/check-arena-config-inventory.py` has the exact offline invocation
`python3 tools/check-arena-config-inventory.py --root . --golden
tools/arena-config-site-golden.json`. It tokenizes Rust source without a
third-party parser: skip line/block comments (including nested block comments),
normal strings, byte strings, raw strings, char literals, and attributes while
retaining identifiers, punctuation, line/column, and balanced delimiters. A
site is counted only when the significant token stream contains a path ending
in the identifier `SwarmConfig` immediately followed by `{`, the token is not
preceded by `struct`, `enum`, `type`, `trait`, `impl`, `fn`, `mod`, `use`, or a
path/type declaration context, and the matching brace contains a top-level
field identifier `arena` followed by `:`. The classifier rejects an item body
whose preceding signature contains `fn`, `impl`, `trait`, or `struct` without
the struct-expression context. It reports stable fingerprints
`relative_path::enclosing_function_or_module::ordinal::top_level_field_digest`
where the field digest is SHA-256 over canonical top-level field names plus the
full normalized expression token values (including literal values, paths, and
the exact default constructor spelling), not merely token kinds or source line
numbers. Thus changing `ArenaConfig::default()` to another default, changing a
literal value, or changing a path token changes the fingerprint and fails the
golden/mutation gate. This is an exact direct-literal classifier, not a raw
`rg` count.

The golden JSON contains the sorted 24 fingerprints, the sorted 23 relative
paths, and one owner (`00`, `00C`, or `00D`) for every site. The expected
ownership partition is three core paths for 00, the ten 00C paths, and the ten
00D paths; no path may appear in two owners. `--self-test` builds an in-memory
fixture corpus and runs mutations: deleting `arena:` fails; adding a new
expression fails; changing `arena: ArenaConfig::default()` to another default
fails; changing a declaration, signature, `impl` header, comment, or string
does not change the count; moving a literal to an unowned path fails; and
duplicating a fingerprint fails. The shell wrapper runs the exact dependent
helper commands `bash tools/check-arena-config-literals.sh --self-test` and
`bash tools/check-arena-config-literals-second-half.sh --self-test`, then their
clean modes, the parser golden check, and these mutations with `mktemp -d` and
an ownership-scoped trap. It never edits signed rulesets or uses broad cleanup.
</interfaces>
