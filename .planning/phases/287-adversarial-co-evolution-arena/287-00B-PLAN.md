<interfaces>
The catalog maps finite `TacticId`/`TechniqueId` pairs to a closed
`FixturePrimitive` and closed `FixtureTargetId`. The only runtime target
constructor permitted later is `swarm_arena::fixture::FixtureTarget::from_id`,
which returns an in-memory/run-owned synthetic target and rejects every unknown
ID. No fixture target is a path or network address.

The partition manifest carries canonical entry/content/partition digests plus a
detached signature envelope (`state_kind=arena.partition.index`, signer key
ID, sequence, signature). The YAML is not itself claimed to be a signature;
the arena admission verifier checks the envelope and canonical bytes. This
keeps the static oracle's digest claim consistent with the runtime signature
claim.

The baseline fixes integer units and arithmetic:

```text
time_improvement_bp = (control_median_virtual_ms - learned_median_virtual_ms)
                      * 10_000 / control_median_virtual_ms; require control > 0 and >= 1_500 bp
blast_radius_delta_units = learned_median_asset_impact_units - control_median_asset_impact_units;
                           require <= 0 units
learning_improvement_bp = (learned_score_bp - control_score_bp)
                          * 10_000 / control_score_bp
require control_score_bp > 0 and learning_improvement_bp >= 1_000 bp
withheld_loss_bp = (in_sample_score_bp - withheld_score_bp)
                   * 10_000 / in_sample_score_bp; require in_sample > 0 and <= 500 bp
```

All division uses checked integer arithmetic with declared rounding (floor for
improvement, ceiling for loss). A zero or absent control/in-sample denominator
is a hard oracle failure; no fallback denominator is permitted. The
known-evasion set is frozen by digest and
uses `tactic_id|technique_id|fixture_primitive|order_relation|timing_bucket`;
event IDs, worker counts, and generation numbers are never fingerprints.
</interfaces>
