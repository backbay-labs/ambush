`BlueRuntimeAdapter::run` accepts `&SignedBlueLearnedState`, verifies this
bound, calls `select_patches(seed)` and then `apply_detector_profile` before
`build_composite_detector`, and calls `apply_graph_strategy` before constructing
the Phase 286 bridge. These methods must select a bounded, canonical candidate patch and return an actual
`DetectionConfig`/`GraphInvestigationStrategy` value: a digest-only annotation
is not an accepted learned state. A detector patch changes at least one real
`DetectionConfig` field (`strategy`, `high_confidence_threshold`, or
`medium_confidence_threshold`, with basis points converted to the existing
`f64` threshold units as `bp / 10_000.0`) while preserving the other fields,
and a graph patch changes the strategy ID or policy mode before its canonical
policy digest is recomputed. `DetectorStrategyFamily`, `GraphStrategyId`, and
`GraphPolicyMode` are closed enums; unknown strings, duplicate vocabulary,
unsupported detector families, and arbitrary response/command values are hard
errors. `select_patches(seed)` iterates the `BTreeMap` in canonical candidate-ID
order, computes `sha256(seed || generation || candidate_id || candidate_digest)`
for each eligible candidate, and chooses the lexicographically smallest tuple
`(candidate_kind, selection_hash, candidate_id, candidate_digest)` separately
for detector and graph patches. It never depends on hash-map order, task order,
worker count, or host entropy; a tie is resolved by candidate ID then digest.
The empty/frozen state
returns the unchanged baseline and is the paired control; it cannot be silently
replaced by a mutable global or by a changed event ID.

The Phase 286 strategy contract is mode-bearing, not digest-only:
`GraphInvestigationStrategy` has the exact fields
`{ strategy_id: String, detector_profile_digest: String,
graph_policy_mode: swarm_core::hypothesis_graph::GraphPolicyMode,
graph_policy_digest: String, memory_digest: Option<String> }`. Its constructor
is `GraphInvestigationStrategy::new(strategy_id, detector_profile_digest,
graph_policy_digest, graph_policy_mode, memory_digest)`, and it recomputes or
validates `graph_policy_digest` from canonical policy bytes containing the
closed mode. The mapping is behavioral: `EvidenceFirst` requires evidence
coverage before an edge contributes to convergence; `ChallengeContradictions`
always emits challenge/falsification work for conflicting edges and retains
alternatives; `ConservativeContainment` admits only reversible, bounded-
blast-radius simulation options after the evidence/policy checks. A learned
graph patch must change the selected mode or strategy ID and the next graph
task/convergence/containment result; changing only `graph_policy_digest` or an
event ID is a hard no-op refusal. Mutation tests flip each mode and delete the
mode application, and must observe a changed typed graph behavior or fail.
```
