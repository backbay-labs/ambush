<objective>
Enforce signed pheromone deposits across the substrate and all deposit-producing agents.

Purpose: Close HARDEN-01 — unsigned deposits represent a trust gap where any code path could inject fake pheromone signals into the substrate. Signing ensures every deposit is attributable to a verified agent identity.

Output: Substrate rejects unsigned deposits; WhiskerAgent and StalkerAgent sign every deposit they produce.
</objective>


    3. Create a free function `validate_deposit_signature(deposit: &PheromoneDeposit) -> Result<(), SubstrateError>` in `substrate.rs` that:
       - Returns `Err(SubstrateError::InvalidDeposit { reason: "empty signature".into() })` if `deposit.signature.is_empty()`
       - Returns `Err(SubstrateError::InvalidDeposit { reason: "empty agent_key".into() })` if `deposit.agent_key.is_empty()`
       - Attempts to construct an `ed25519_dalek::VerifyingKey` from `deposit.agent_key` (32 bytes); returns `InvalidDeposit` on failure
       - Attempts to construct an `ed25519_dalek::Signature` from `deposit.signature` (64 bytes); returns `InvalidDeposit` on failure
       - Constructs a canonical signing payload: JSON-serialize the deposit's `indicator`, `threat_class`, `severity`, `confidence`, `timestamp`, `decay_half_life`, and `agent_id` fields into a deterministic byte string using `serde_json::to_vec` on a tuple/struct of those fields (exclude signature and agent_key themselves)
       - Verifies the signature using `verifying_key.verify(payload, signature)`; returns `InvalidDeposit` on failure
       - Returns `Ok(())` on success

    4. Call `validate_deposit_signature(&deposit)?` at the top of `InMemoryPheromoneSubstrate::deposit()`, `LocalJournalPheromoneSubstrate::deposit()`, and the `ConfiguredPheromoneSubstrate::deposit()` dispatcher (validate once in the ConfiguredPheromoneSubstrate dispatch so backends don't need individual checks — OR validate in each backend; either approach works, but doing it in `ConfiguredPheromoneSubstrate::deposit()` before delegation is cleanest).

    5. Add `use ed25519_dalek::{Signature as DalekSignature, Verifier, VerifyingKey};` to substrate.rs imports.

    6. For the canonical signing payload, create a small serializable struct:
       ```rust
       #[derive(serde::Serialize)]
       struct DepositSigningPayload<'a> {
           indicator: &'a serde_json::Value,
           threat_class: &'a ThreatClass,
           severity: &'a swarm_core::types::Severity,
           confidence: f64,
           timestamp: i64,
           decay_half_life: f64,
           agent_id: &'a swarm_core::types::AgentId,
       }
       ```

    7. Write tests in `substrate.rs` module tests using `ed25519_dalek::SigningKey` to create valid signed deposits and verify that unsigned/invalid deposits are rejected.
