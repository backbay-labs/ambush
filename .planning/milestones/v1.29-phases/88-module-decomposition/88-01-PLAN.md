<objective>
Extract all CLI logic from the 3,512-line swarmctl binary into testable library modules under `src/cli/`, reducing the binary to a thin wrapper under 300 lines.

Purpose: The swarmctl binary currently contains all parsing, dispatch, harness construction, and output formatting inline in `main()`, making it impossible to test any CLI logic with `cargo test`. Moving this into library modules enables unit testing of argument parsing, dispatch routing, and output formatting.

Output: A `cli/` module directory with `args.rs` (definitions), `dispatch.rs` (execution), and `format.rs` (output helpers), plus a stripped-down `bin/swarmctl.rs` that calls `cli::dispatch::run()`.
</objective>
