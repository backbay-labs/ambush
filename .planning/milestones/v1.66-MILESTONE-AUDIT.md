## Cross-Phase Integration

The milestone contract is coherent end to end:

- Phase 232 introduced the shared `swarm_core::signed_state` envelope and bound behavioral baseline persistence to signer-aware verification instead of unsigned restore trust.
- Phase 233 reused that signed-state contract for Sphinx graph snapshots, which proves the persistence and restart seam works beyond one learned-state backend.
- Phase 234 extended the same signer and verification model into evolution population and episode artifacts without breaking the existing mutation harness and Kitten restore path.
- Phase 235 completed the contract by enforcing monotonic `sequence` ordering across every signed learned-state stream, so trusted restore now rejects both tamper and older replayed state.

## E2E Flows Verified

1. Behavioral baseline snapshots now sign before persistence, rehydrate after restart only when trusted, and fail closed on tamper or replay.
2. Sphinx graph state now persists through a signed authoritative snapshot path and refuses unsigned, tampered, or replayed graph files on restart.
3. Evolution population and episode artifacts now persist and restore through the same signer-aware contract, preserving durable lineage without reopening unsigned side channels.
4. Shared monotonic replay prevention now makes the newest accepted learned-state artifact authoritative across behavioral, graph, population, and episode stores.
