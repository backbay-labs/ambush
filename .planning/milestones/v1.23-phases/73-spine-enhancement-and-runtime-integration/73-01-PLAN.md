<objective>
Port signed envelope, checkpoint statement, and hash chain modules from vendor ClawdStrike spine into swarm-spine, wiring to swarm-crypto instead of hush-core.

Purpose: swarm-spine needs cryptographic commitment capabilities (signed envelopes, checkpoint co-signatures, chain verification) for the upcoming approval ledger and governance milestones. The vendor reference code is battle-tested but wired to hush-core; this plan adapts it to swarm-crypto primitives.

Output: Four new source files in swarm-spine (spine_error.rs, envelope.rs, checkpoint.rs, chain.rs) with re-exports from lib.rs, plus workspace chrono dependency.
</objective>
