// Upstream is async -- swarm version will be sync
pub trait Guard: Send + Sync {
    fn name(&self) -> &str;
    fn handles(&self, action: &GuardAction<'_>) -> bool;
    async fn check(&self, action: &GuardAction<'_>, context: &GuardContext) -> GuardResult;
}

pub struct GuardResult {
    pub allowed: bool,
    pub guard: String,
    pub severity: Severity,
    pub message: String,
    pub details: Option<serde_json::Value>,
}

pub enum GuardAction<'a> {
    FileAccess(&'a str),
    FileWrite(&'a str, &'a [u8]),
    NetworkEgress(&'a str, u16),
    ShellCommand(&'a str),
    // ... etc
}

    3. **shell_command.rs**: Port ShellCommandGuard adapted for swarm.

    `ShellCommandConfig` struct: `enabled: bool` (default true), `forbidden_patterns: Vec<String>` (regex strings), `enforce_forbidden_paths: bool` (default true).

    Default forbidden patterns (from upstream):
    - `rm -rf /` pattern: `r"(?i)\brm\s+(-rf?|--recursive)\s+/\s*(?:$|\*)"`
    - curl/wget pipe to shell: `r"(?i)\bcurl\s+[^|]*\|\s*(bash|sh|zsh)\b"`, `r"(?i)\bwget\s+[^|]*\|\s*(bash|sh|zsh)\b"`
    - Reverse shell indicators: `r"(?i)\bnc\s+[^\n]*\s+-e\s+"`, `r"(?i)\bbash\s+-i\s+>&\s+/dev/tcp/"`
    - Base64 exfil: `r"(?i)\bbase64\s+[^|]*\|\s*(curl|wget|nc)\b"`

    Also add swarm-specific patterns:
    - `mkfs` on any device: `r"(?i)\bmkfs\b"`
    - `dd` writing to block device: `r"(?i)\bdd\s+.*of=/dev/"`

    `ShellCommandGuard` struct: `name: String`, `enabled: bool`, `config: ShellCommandConfig`, `forbidden_regexes: Vec<regex::Regex>`, `forbidden_path: ForbiddenPathGuard`.

    `check()` implementation:
    1. Normalize quoted pipe operators (`'|'` -> `|`) for pattern matching
    2. Check each forbidden regex against the normalized command
    3. If `enforce_forbidden_paths`, extract candidate paths from the command using a simplified version of the upstream `extract_candidate_paths` (look for tokens starting with `/`, `~`, `./`, `../`, or containing `/.ssh/`, `/.aws/`, `/.gnupg/`) and check each against the embedded ForbiddenPathGuard
    4. Return allow if no matches

    Port the `shlex_split_best_effort` and `looks_like_path` helper functions from upstream for path extraction. Port `push_path_candidate` for cleaning extracted tokens. Skip `extract_windows_paths_best_effort` and `split_inline_redirection` -- simplify to just the basic token extraction. Port `is_redirection_op` for redirect target extraction.

    Implement `Guard` trait:
    - `name()` returns "shell_command"
    - `handles()` returns true for `ShellCommand` only
    - `check()` as described above
