2. Add `prometheus-client.workspace = true` to `[dependencies]` in `crates/swarm-runtime/Cargo.toml`.

3. Create `crates/swarm-runtime/src/metrics.rs` with:
   - A `CriticalPathMetrics` struct holding a `prometheus_client::registry::Registry` and three `prometheus_client::metrics::histogram::Histogram` fields: `detect_latency_us`, `policy_latency_us`, `response_latency_us`.
   - `CriticalPathMetrics::new()` constructor that creates a `Registry` with prefix `"swarm"`, registers three histograms with descriptive names (`swarm_detect_latency_microseconds`, `swarm_policy_latency_microseconds`, `swarm_response_latency_microseconds`) and help text, using bucket boundaries derived from the existing `LATENCY_BUCKETS_US` constant: `[100.0, 500.0, 1_000.0, 5_000.0, 10_000.0, 50_000.0]` (drop the `u64::MAX` sentinel -- Prometheus uses `+Inf` implicitly).
   - `CriticalPathMetrics::observe_detect(&self, latency_us: f64)` method that calls `self.detect_latency_us.observe(latency_us)`.
   - `CriticalPathMetrics::observe_policy(&self, latency_us: f64)` method.
   - `CriticalPathMetrics::observe_response(&self, latency_us: f64)` method.
   - A public `encode_metrics(metrics: &CriticalPathMetrics) -> String` function that uses `prometheus_client::encoding::text::encode` to produce OpenMetrics-format text from the registry.
   - `CriticalPathMetrics` must implement `Clone` (wrap the registry in `Arc` so it can be shared between the service and the HTTP handler). Note: `prometheus_client::registry::Registry` is NOT Clone, so store it as `Arc<Mutex<Registry>>` or use the pattern where you keep the registry separate. The recommended approach: store `Arc<Mutex<Registry>>` inside `CriticalPathMetrics` alongside the histogram handles (which ARE Clone).
   - Add `#[cfg(test)] mod tests` with a basic test: create `CriticalPathMetrics`, observe a few values, call `encode_metrics`, assert the output contains `swarm_detect_latency_microseconds`, `swarm_policy_latency_microseconds`, `swarm_response_latency_microseconds`, and the `# TYPE` / `# HELP` lines.

4. Add `pub mod metrics;` to `crates/swarm-runtime/src/lib.rs` (in the existing module list, alphabetically near `mutation`).
