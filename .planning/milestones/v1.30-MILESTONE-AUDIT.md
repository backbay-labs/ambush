# Milestone v1.30 Audit

## Summary

`v1.30 Structured Observability And Adapter Resilience` achieved its definition of done. The runtime now emits correlation-aware structured JSON logs, exposes decision counters alongside latency histograms, hardens HTTP EDR and webhook execution with retry and circuit-breaker behavior, persists exhausted failures to a dead-letter journal, separates readiness from liveness probes, and rejects invalid detector profile payloads during config load instead of at runtime.

| OBS-03 | 91 | passed | satisfied | HTTP EDR and webhook adapters now run behind retry/backoff and circuit-breaker logic. |
