# Milestone v1.35 Audit

## Summary

`v1.35 Production Hardening And Kubernetes Lifecycle` achieved its definition of done. The serve-mode runtime now supports drain-aware PreStop shutdown and startup-only probing, runtime config is schema-aware and can resolve rotating adapter secrets from mounted files or environment variables, heap pressure is exported and used to shed readiness before OOM, and the repo now ships an operator-facing disaster-recovery runbook for the hardened runtime.
