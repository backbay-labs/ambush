<objective>
Add /readyz and /livez Kubernetes probe endpoints and implement threshold validation on all detector profiles.

Purpose: /healthz conflates liveness and readiness, making Kubernetes probes unreliable. Detector profiles currently accept any numeric value including nonsensical ones (negative entropy, confidence > 1.0), which produces silent misbehavior at runtime instead of failing fast at config load.

Output: Two new axum routes in ingest.rs, validate() methods on all 5 detector profile structs, validation integrated into the detector construction path.
</objective>
