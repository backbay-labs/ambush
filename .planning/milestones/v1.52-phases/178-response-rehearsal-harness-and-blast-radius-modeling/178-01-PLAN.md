# Phase 178 Plan 01

## Goal

Complete Phase 178 by exposing one bounded response rehearsal workflow that reuses the live policy and execution path in dry-run mode and attaches typed blast-radius plus rollback evidence before any live approval decision.

## Why This Order

1. The blast-radius and rollback preview must exist first so rehearsal has something meaningful to prove.
2. Rehearsal should then execute through the existing runtime dry-run seam to preserve policy and approval parity.
3. Persistence and verification come last so later review surfaces can build on stable rehearsal artifacts instead of transient logs.

## Tasks

### Task 1: Add Typed Rehearsal Preview Models

- Define typed blast-radius and rollback preview data for the currently supported response actions.
- Derive those previews directly from `ActionRequest` and scoped lease context rather than from separate operator-only input.

Done when:

- Rehearsal can explain affected scope, bounded impact, and rollback procedure before execution.
- Preview generation fails closed when scope or action metadata is insufficient.

### Task 2: Reuse The Existing Dry-Run Runtime Path

- Expose a rehearsal entry point that routes through the same policy, approval, and executor path as live response while forcing `ExecutionMode::DryRun`.
- Preserve the simulated receipt and policy audit so rehearsal proves the same gate decisions live execution would face.

Done when:

- Rehearsal cannot create live side effects.
- Rehearsal still emits the same policy and response receipt structure used by the normal runtime.

### Task 3: Persist Rehearsal Proof And Verify No Live Side Effects

- Persist rehearsal artifacts with the request, preview, simulated receipt, and audit trail needed for later review.
- Add tests proving rehearsal uses dry-run execution, carries blast-radius and rollback evidence, and does not bypass policy.

Done when:

- Rehearsal artifacts are durable and self-describing.
- Tests prove rehearsal stays on the live execution path while remaining non-destructive.
