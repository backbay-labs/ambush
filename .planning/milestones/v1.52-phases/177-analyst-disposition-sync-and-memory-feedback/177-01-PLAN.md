# Phase 177 Plan 01

## Goal

Complete Phase 177 by persisting analyst dispositions as durable signed evidence and routing bounded outcome signals into Sphinx memory and existing Kitten false-positive feedback lanes.

## Why This Order

1. Durable evidence must land first so the later memory and review surfaces have a stable lineage anchor.
2. Sphinx memory adjustments should reuse that same evidence seam rather than inventing a second feedback model.
3. Verification needs both the Providence feedback handler and the Sphinx retrieval path exercised together so the phase proves real downstream effect, not just data storage.

## Tasks

### Task 1: Persist Signed Analyst Evidence On Incident Audit Entries

- Extend the shared feedback evidence model and incident audit entry to retain a durable summary of the Swarm-signed Providence feedback deposit.
- Update the Providence feedback handler to generate one stable `feedback_id`, reuse it across the signed deposit and audit entry, and record the signed evidence summary in durable incident storage.

Done when:

- Every Providence feedback action persists one incident-linked audit entry with stable feedback identity and signed-evidence metadata.
- The audit entry remains self-describing after transient substrate state expires.

### Task 2: Feed Bounded Analyst Outcomes Into Sphinx Memory

- Teach Sphinx to recognize Providence feedback deposits and bind them to the matching engagement by event or hunt identity.
- Persist the latest analyst disposition, note, and bounded outcome reward on the engagement so future memory queries reflect analyst-confirmed or analyst-dismissed context.

Done when:

- A dismiss action can zero the matching engagement's memory reward.
- A confirm or investigate action leaves durable analyst context on the engagement without creating duplicate observations.

### Task 3: Verify End-To-End Disposition Routing

- Extend Providence feedback tests to assert durable signed evidence is stored.
- Add Sphinx coverage proving analyst feedback updates the engagement reward used by memory retrieval.
- Update operator-facing configuration notes for the Providence signed ingress contract.

Done when:

- Providence feedback tests prove evidence lineage is durable.
- Sphinx tests prove analyst dispositions change retrieval output for the matching engagement.
