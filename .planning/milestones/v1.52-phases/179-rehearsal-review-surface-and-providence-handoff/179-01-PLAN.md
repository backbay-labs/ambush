# Phase 179 Plan 01

## Goal

Complete Phase 179 by surfacing rehearsal and reconciliation context together on the bounded local review path, tightening Providence drilldown links to that same context, and making rehearsal replay bundles exportable as signed proof without inventing a new proof format.

## Why This Order

1. The local read-only surfaces need rehearsal and reconciliation metadata first so Providence and operators land on the same bounded context.
2. Providence handoff links should then target those bounded surfaces rather than a generic review home.
3. Signed proof export comes last so it can reuse the stabilized local review identifiers and replay-bundle context.

## Tasks

### Task 1: Surface Rehearsal And Reconciliation Together

- Extend the local platform/review read path so replay-backed findings and incident views can show rehearsal proof and the latest reconciliation summary in one bounded context.
- Add any minimal query parameters or contextual cards needed on the operator review home/replay surfaces so Providence links can land on the right hunt or incident immediately.

Done when:

- Local review can show the latest rehearsal proof and reconciliation state together for the same hunt or incident.
- Rehearsal artifacts remain clearly marked as dry-run-only.

### Task 2: Tighten Providence Handoff Links

- Update Providence drilldown link generation so replay and review links carry the bounded hunt, incident, and rehearsal context already enforced by the existing token contract.
- Preserve read-only semantics; do not widen Providence access beyond the current scoped GET surfaces.

Done when:

- Providence links no longer drop analysts onto an unscoped generic review home.
- Handoff links still validate under the current context-token rules.

### Task 3: Export Signed Rehearsal Proof Packages

- Reuse the existing replay-bundle evidence export format to create signed proof packages for rehearsal bundles from the operator surface.
- Add tests proving the exported proof is signed, stable, and tied to the rehearsal replay bundle rather than a new bespoke artifact type.

Done when:

- Rehearsal replay bundles can be turned into signed proof packages through the existing evidence contract.
- Local review and Providence handoff surfaces can point at that signed proof package or its stable review location.
