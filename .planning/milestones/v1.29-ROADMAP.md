## Phase Details

### Phase 88: Module Decomposition
**Goal**: The 4 largest monolithic files in swarm-runtime are split into focused, bounded modules and the swarmctl binary is reduced to a thin CLI wrapper
**Depends on**: Nothing (first phase of v1.29)
**Requirements**: REFAC-01, REFAC-02, REFAC-03, REFAC-04
**Success Criteria** (what must be TRUE):
  1. `swarmctl` binary is under 300 lines and all CLI parsing, dispatch, and formatting logic lives in library modules that can be tested with `cargo test`
  2. `operator_http.rs` no longer exists as a single file; its route handlers live behind focused HTTP modules
  3. `review_workbench.rs` no longer exists as a single file; its logic lives behind focused workbench modules
  4. `replay.rs` no longer exists as a single file; its logic lives behind focused replay modules
  5. `cargo build --workspace && cargo test --workspace && cargo clippy --workspace -- -D warnings` passes with zero regressions
**Plans**: 3/3 plans complete

Plans:
- [x] 88-01-PLAN.md -- Extract swarmctl CLI logic into testable cli/ library modules
- [x] 88-02-PLAN.md -- Split operator_http.rs into focused http/ route modules
- [x] 88-03-PLAN.md -- Split review_workbench.rs and replay.rs into focused submodules

### Phase 89: Test Coverage And Hot-Path Consolidation
**Goal**: The newly-split modules have meaningful test coverage and hot-path detection modules are consolidated into a detection/ submodule with clear boundaries
**Depends on**: Phase 88
**Requirements**: TEST-01, TEST-02, TEST-03
**Success Criteria** (what must be TRUE):
  1. `cargo llvm-cov` or equivalent reports materially improved swarm-runtime coverage
  2. `ingest.rs` has tests covering event validation, HTTP error responses, and batch processing edge cases
  3. Hot-path modules (pipeline, service, detection logic) live under a `detection/` submodule with a single public re-export boundary
  4. The largest previously-untested modules have direct regression coverage on their primary public surfaces
**Plans**: 2/2 plans complete

Plans:
- [x] 89-01-PLAN.md -- Consolidate pipeline.rs and metrics.rs into detection/ submodule with public re-export boundary
- [x] 89-02-PLAN.md -- Add test coverage to ingest.rs and the largest decomposed runtime surfaces
