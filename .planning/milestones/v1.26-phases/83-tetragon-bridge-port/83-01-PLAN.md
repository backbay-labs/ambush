    **BridgeConfig**:

    }

    **TetragonBridge**:
    ```rust

        config: BridgeConfig,
    }
    ```

    **Primary method** -- `run()`:
    ```rust
    pub async fn run(
        &self,
        tx: tokio::sync::mpsc::Sender<TelemetryEvent>,
    ) -> Result<()>
    ```

    The run method:
    1. Connects to Tetragon via `TetragonClient::connect(&self.config.tetragon_endpoint)`
    2. Opens event stream with configured event type filters
    3. Loops over stream messages:
       - On `Ok(Some(resp))`: classify event kind. If ProcessExec, call `map_process_exec`. If mapping returns Some, send to `tx`. If ProcessExit/ProcessKprobe, log at debug and skip. If Unknown, skip.
       - On mapping/send error: increment consecutive_errors, log warning, apply backoff sleep (100ms base, doubling to 30s max), check against max_consecutive_errors limit
       - On success: reset consecutive_errors and backoff
       - On `Ok(None)`: stream ended, return Ok (caller decides to reconnect)
       - On `Err(e)`: return Err (stream-level gRPC failure)
    4. If `tx.send()` fails (receiver dropped), return `Error::ChannelClosed`

    **Reconnecting wrapper** -- `run_with_reconnect()`:
    ```rust
    pub async fn run_with_reconnect(
        &self,
        tx: tokio::sync::mpsc::Sender<TelemetryEvent>,
        shutdown: tokio::sync::watch::Receiver<bool>,
    ) -> Result<()>
    ```
    Outer loop: call `run()`, on stream-end or connection error, check shutdown signal, apply reconnect backoff (1s base, doubling to 60s max), retry. On shutdown signal, return Ok.

    Update `lib.rs` to add `pub mod bridge;` and re-export `TetragonBridge`, `BridgeConfig` from the crate root.

Test the consecutive error counting and max-error bail-out logic separately from the gRPC connection (which requires a real server).

    Note: Full integration tests against a real Tetragon instance are out of scope. The unit tests validate mapping correctness, event filtering, and error counting. The gRPC connection path is tested by compilation (the types work) and manually when a Tetragon instance is available.
