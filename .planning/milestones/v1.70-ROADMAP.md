# Roadmap Snapshot: v1.70 Telemetry Source Breadth

Shipped: 2026-04-13

## Goal

Ship Windows Event Log, Sysmon, and auditd bridge adapters through the existing bridge runtime and operator surfaces.

## Executed Phases

- [x] **Phase 248: Windows Event Log Bridge** - Added a repo-configured Windows Event Log bridge with shared auth and process payload mapping.
- [x] **Phase 249: Sysmon Bridge** - Added a Sysmon bridge with shared process, network, and file payload mapping.
- [x] **Phase 250: Auditd Bridge** - Added an auditd bridge with shared auth, execve, network, and file mapping.
- [x] **Phase 251: Bridge Health And Metrics Integration** - Proved the three new bridges run through the shared registry, operator readiness, health, metrics, and detector pipeline.

## Delivered Outcome

- `TelemetryBridgeConfig` now supports `windows_event_log`, `sysmon`, and `auditd` bridge-backed sources.
- `swarm-ingest-json` now ships repo-owned `WindowsEventLogBridge`, `SysmonBridge`, and `AuditdBridge` adapters on the existing file-backed JSON source seam.
- The runtime bridge registry, readiness probe, and health/metrics surfaces now handle the three new bridges without special-casing downstream detector or operator flows.
