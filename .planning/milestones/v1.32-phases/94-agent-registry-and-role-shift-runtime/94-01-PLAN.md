<objective>
Replace the dispatcher's positional agent list with a keyed multi-agent registry and add the event-bus primitive that lets agents change roles at runtime.

Purpose: Phase 92 proved that one agent could run on a tick loop. This plan upgrades that foundation so the runtime can hold a real roster of agents, propagate role changes across the swarm, and prepare the live dispatcher for future dynamic registration and multi-agent coordination work.

Output: A keyed `AgentRegistry`, a `SwarmEvent` broadcast hook on `SwarmAgent`, mutable role state for `WhiskerAgent`, and focused tests covering registration, deregistration, and role-shift propagation.
