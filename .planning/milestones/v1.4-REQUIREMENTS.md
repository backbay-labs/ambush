## Completed Requirements

### Adversarial Replay Corpus

- [x] **RED-01**: Team can run Hellcat-inspired adversarial scenario corpora against the offline replay harness
- [x] **RED-02**: Team can group adversarial scenarios into named suites with campaign, technique, and benign-vs-adversarial metadata for repeatable execution
- [x] **RED-03**: Evaluation reports can identify which adversarial scenarios, suites, or technique groups regressed

### Strategy Experiments

- [x] **EVO-01**: Team can register a candidate detection strategy as a repo-owned experiment input without changing the production detector configuration
- [x] **EVO-02**: Team can compare baseline and candidate strategies against the same replay corpus on detection quality, false positives, and latency
- [x] **EVO-03**: Candidate strategy experiments persist lineage, corpus version, and score summaries for offline review
- [x] **EVO-04**: Offline experiment gates fail when a candidate regresses known-bad coverage or misses configured comparison thresholds
