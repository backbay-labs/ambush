## Phase Details

### Phase 92: Agent Dispatcher And WhiskerAgent
**Goal**: The runtime has a tick-based agent execution loop with the detection pipeline wrapped as an agent
**Depends on**: Phase 91 (v1.30 complete)
**Requirements**: AGENT-01, AGENT-02
**Success Criteria** (what must be TRUE):
  1. `AgentDispatcher` manages a `Vec` of registered `SwarmAgent` implementations
  2. The dispatcher runs each agent's `tick()` on a configurable interval (default 100ms)
  3. `WhiskerAgent` implements `SwarmAgent`, calling `detect_and_deposit` on each tick with buffered telemetry
  4. The dispatcher integrates into `swarm-detect` serve mode alongside ingest and metrics
  5. Agent health is reported in `/healthz`
**Plans**: 1/1 plans complete

Plans:
- [x] 92-01-PLAN.md -- Add the dispatcher loop, wrap the detection pipeline as `WhiskerAgent`, and wire buffered ingest events plus agent health into serve mode

### Phase 93: Pheromone Escalation And Mode Transitions
**Goal**: The runtime reacts to pheromone concentration by transitioning modes and emitting escalation events
**Depends on**: Phase 92
**Requirements**: AGENT-03, AGENT-04, AGENT-05
**Success Criteria** (what must be TRUE):
  1. A concentration monitor queries the substrate on a configurable interval
  2. When `total_strength` exceeds `alert_threshold` and `distinct_sources >= min_sources`, an `AlertEscalation` event is emitted
  3. When `total_strength` exceeds `incident_threshold` and `distinct_sources >= min_sources`, an `IncidentEscalation` event is emitted
  4. Mode transitions are logged, metriced, and persisted as durable state
  5. Integration tests with two mock agents depositing to a shared substrate prove: below threshold -> no escalation, single source -> no escalation, dual source above threshold -> escalation fires
**Plans**: 2/2 plans complete

Plans:
- [x] 93-01-PLAN.md -- Add typed escalation events, monotonic mode state, and a concentration monitor over the pheromone substrate
- [x] 93-02-PLAN.md -- Add integration tests proving threshold crossing and the multi-source escalation gate
