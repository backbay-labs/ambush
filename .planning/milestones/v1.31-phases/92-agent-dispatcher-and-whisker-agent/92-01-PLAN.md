<objective>
Implement a tick-based agent dispatcher in swarm-runtime and the first SwarmAgent implementation (WhiskerAgent) that wraps the existing detection pipeline.

Purpose: This is the foundation for the swarm agent execution model. The dispatcher gives the runtime a uniform way to run any number of SwarmAgent implementations on a tick loop, and WhiskerAgent proves the model by wrapping the existing detect_and_deposit pipeline as an agent that processes buffered telemetry.

Output: Two new modules (dispatcher.rs, whisker_agent.rs), updated ingest handler with telemetry channel, updated swarm_detect binary with dispatcher integration, and agent health in /healthz.
</objective>

This means the WhiskerAgent re-processes events that the ingest handler already processed -- this is the intended design for v1 where the agent tick provides a second pass. (Alternative: send BEFORE process_event and have WhiskerAgent be the sole processor. But that changes the existing ingest semantics. Keep the dual-path for now.)

    Actually -- reconsider. The key insight from the requirements: "WhiskerAgent implements SwarmAgent, calling detect_and_deposit on each tick with buffered telemetry." The ingest handler currently calls `stack.process_event()` which internally calls `detect_and_deposit`. If WhiskerAgent ALSO calls `detect_and_deposit`, we get double detection. The cleaner design: the ingest handler buffers raw events into the channel WITHOUT running them through the pipeline. WhiskerAgent becomes the sole detection path. But this changes existing ingest behavior significantly.

    Safer v1 approach: The telemetry channel feeds the WhiskerAgent with events that the ingest handler accepted (validated and parsed). WhiskerAgent's tick calls detect_and_deposit. The ingest handler STILL runs the full pipeline for immediate HTTP response (accepted/rejected). The agent tick is an async second pass that deposits pheromones from the agent's identity, enabling the swarm model. This dual-path is intentional -- the ingest pipeline is the request/response path, WhiskerAgent is the swarm detection path. In Phase 93, pheromone concentration from agent deposits drives escalation.
