<objective>
Implement the escalation event types and concentration monitor that drives pheromone-based mode transitions.

Purpose: The swarm needs to react to accumulated pheromone concentration by shifting its operating mode. This plan creates the escalation event vocabulary in swarm-core and the ConcentrationMonitor in swarm-runtime that polls the substrate and emits mode transitions when dual-gated thresholds (strength AND source diversity) are crossed.

Output: EscalationEvent types in swarm-core, SwarmModeState for durable mode tracking, ConcentrationMonitor struct in swarm-runtime/src/escalation.rs with unit tests.

<task type="auto" tdd="true">
  <name>Task 2: Implement ConcentrationMonitor in swarm-runtime</name>
  <files>crates/swarm-runtime/src/escalation.rs, crates/swarm-runtime/src/lib.rs</files>
  <behavior>
    - ConcentrationMonitor::new() accepts PheromoneConfig and Arc substrate
    - evaluate_threat_class() returns Option EscalationEvent when thresholds are crossed
    - evaluate_all() iterates the standard ThreatClass variants, returns Vec of EscalationEvent
    - Below alert_threshold: no event returned
    - Above alert_threshold but below incident_threshold with sufficient sources: AlertEscalation
    - Above incident_threshold with sufficient sources: IncidentEscalation
    - Above any threshold but only 1 source: no event (min_sources gate)
    - Mode state tracks transitions: first alert transitions Normal->Alert, subsequent alerts for same mode are still emitted but mode stays Alert
    - Reaching incident threshold transitions Alert->Incident
  </behavior>
  <action>
    Create `crates/swarm-runtime/src/escalation.rs`:

    Define `EscalationOutcome` struct:
    ```rust
    #[derive(Debug, Clone)]
    pub struct EscalationOutcome {
        pub events: Vec<EscalationEvent>,
        pub mode_changed: bool,
        pub current_mode: SwarmMode,
    }
    ```

    Define `ConcentrationMonitor` struct:
    ```rust
    pub struct ConcentrationMonitor<S: PheromoneSubstrate> {
        config: PheromoneConfig,
        substrate: Arc<S>,
        mode_state: SwarmModeState,
    }
    ```

    Implement:
    - `new(config: PheromoneConfig, substrate: Arc<S>) -> Self` -- starts with SwarmModeState::new()
    - `mode_state(&self) -> &SwarmModeState` -- read access for external consumers
    - `async evaluate_threat_class(&mut self, threat_class: &ThreatClass, now: i64) -> Result<Option<EscalationEvent>, SubstrateError>`:
      - Call `self.substrate.query_concentration(threat_class, now).await`
      - Check `concentration.exceeds_threshold(self.config.incident_threshold, self.config.min_sources_for_escalation)` first (higher threshold wins)
      - If incident threshold crossed: return `Some(EscalationEvent::Incident { ... })`
      - Else check `concentration.exceeds_threshold(self.config.alert_threshold, self.config.min_sources_for_escalation)`
      - If alert threshold crossed: return `Some(EscalationEvent::Alert { ... })`
      - Otherwise: return `None`
    - `async evaluate_all(&mut self, now: i64) -> Result<EscalationOutcome, SubstrateError>`:
      - Iterate over a fixed list of standard ThreatClass variants (all non-Custom variants)
      - Call `evaluate_threat_class` for each
      - Collect all Some events into a Vec
      - For each event, call `mode_state.transition_to()` with the appropriate mode and record whether any transition happened
      - Log each escalation event with `tracing::warn!` including threat_class, total_strength, distinct_sources, and new mode
      - Log mode transitions with `tracing::info!` including from_mode, to_mode, and trigger
      - Return `EscalationOutcome { events, mode_changed, current_mode }`

    For the standard threat class list, define a const or function:
    ```rust
    fn standard_threat_classes() -> &'static [ThreatClass] { ... }
    ```
    Since ThreatClass variants aren't Copy (Custom contains String), use a function that returns a Vec or use lazy static. Simplest: a function returning `vec![ThreatClass::LateralMovement, ...]` covering all non-Custom variants.

    - Test: above alert with 2 sources returns AlertEscalation
    - Test: above incident with 2 sources returns IncidentEscalation (not AlertEscalation)
    - Test: mode transitions from Normal to Alert to Incident correctly
    - Test: repeated alerts don't de-escalate from Incident back to Alert

    Use `InMemoryPheromoneSubstrate` in tests, deposit with `sample_deposit` helper similar to substrate tests. Use two different agent_ids to satisfy min_sources.
