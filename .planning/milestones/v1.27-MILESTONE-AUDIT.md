# Milestone v1.27 Audit

## Summary

`v1.27 Live Response Adapters And Deployment` achieved its definition of done. The repo now ships generic HTTP EDR and webhook response adapters selected from runtime config, preserves dispatched success and failure outcomes in the audit trail, exposes `/healthz` with reload-aware service readiness, and packages the detection service into a small compose-driven container image with an optional internal NATS sidecar.

## Notes

- The builder image had to move from `rust:1.85-bookworm` to `rust:1.94-bookworm` because the current lockfile includes crates that now require Rust 1.86 or newer.
- The NATS sidecar is intentionally internal-only in compose so the profile can start on developer machines that already have a host NATS instance bound to port `4222`.
- Nyquist validation artifacts are still absent for phases 84 and 85 and remain follow-up work.
