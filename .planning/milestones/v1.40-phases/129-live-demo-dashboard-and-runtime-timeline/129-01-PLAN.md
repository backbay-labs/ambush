# Phase 129: Live Demo Dashboard And Runtime Timeline - Plan

## Goal

Render a live demo dashboard on the operator review home page using runtime-owned snapshot data plus the streamed runtime event backbone from Phase 128.

## Tasks

1. Extend runtime configuration and shared state.
   - Add `operator_surface.runtime_base_url` with a local-runtime default and validation.
   - Carry the configured base URL into `OperatorHttpState`.
   - Store shared swarm mode state in `IngestState` so the runtime HTTP surface can expose current mode.

2. Add runtime dashboard data contracts and handlers.
   - Add a typed concentration snapshot runtime event payload.
   - Emit concentration snapshot events from the concentration monitor on each evaluation cycle.
   - Add a demo dashboard snapshot endpoint on the runtime server that returns mode, agent health, concentrations, and recent escalations.
   - Add GET CORS headers for the demo snapshot and SSE handlers.

3. Upgrade the operator review home page into the live dashboard.
   - Add dashboard sections for current swarm mode, agent health, pheromone concentrations, and a runtime timeline.
   - Embed the runtime base URL and lightweight client-side logic to fetch the snapshot once and subscribe to the runtime SSE stream.
   - Preserve existing review tables and quick links below the new live dashboard.

4. Verify and close the phase.
   - Add targeted ingest tests for the new snapshot endpoint and concentration event filtering.
   - Extend operator-surface tests to assert the review home page includes dashboard bootstrap wiring.
   - Update roadmap, requirements, state, summary, and verification artifacts after tests pass.
