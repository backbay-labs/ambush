## Cross-Phase Integration

The milestone contract is coherent end to end:

- Phase 192 made startup attestation a first-class admission decision for
  binary and repo-owned ruleset trust.
- Phase 193 extended that same trust chain to mutable runtime config files so
  startup and full reload no longer trust unsigned config bytes.
- Phase 194 added continuous runtime self-monitoring, preserving the attested
  startup boundary into live operation through surfaced anti-tamper state and
  structured tamper alerts.
- Phase 195 closed the loop on build and release integrity by enforcing
  dependency policy in CI and shipping per-crate SBOM artifacts for tagged
  releases.

## E2E Flows Verified

1. `swarm_detect` now refuses `live_response` mode when binary, ruleset, or
   signed config attestation is not ready.
2. Runtime health and status surfaces carry both startup attestation and the
   latest anti-tamper report, so operators can inspect integrity state after
   startup without a parallel control path.
3. Live runtime monitoring can emit structured tamper alerts and optionally
   fail closed on supported Linux deployments.
4. CI and release automation now use shared repo-owned supply-chain and SBOM
   scripts, so release metadata follows the same integrity contract as local
   verification.
