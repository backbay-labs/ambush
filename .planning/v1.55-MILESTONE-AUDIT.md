## Cross-Phase Integration

The milestone contract is coherent end to end:

- Phase 188 introduced one repo-owned NATS JetStream harness with deterministic
  lifecycle and reusable local plus CI entrypoints.
- Phase 189 moved the substantive pheromone substrate contract onto that real
  backend so the durable topology is no longer a smoke-tested special case.
- Phase 190 added a Criterion-owned hot-path benchmark inside `swarm-runtime`,
  giving the repo a reproducible latency baseline for ingest -> detect ->
  deposit -> escalate.
- Phase 191 extended the existing operator-facing ingest benchmark into a
  measured steady-state plus readiness-shed artifact, so operators can compare
  the full HTTP ingest path against a documented host profile and heap budget.

## E2E Flows Verified

1. The repo can start JetStream automatically and run durable substrate tests in
   both local development and CI without manual infrastructure setup.
2. The hot path now has a repo-owned Criterion benchmark with checked-in p50,
   p95, and p99 latency numbers for later regression comparison.
3. The shipped HTTP ingest benchmark can report both a steady-state envelope and
   the first `/readyz` shed stage on the real runtime path.
4. The docs and configuration reference now distinguish detector-only latency,
   steady-state ingest behavior, and readiness-shed sizing so future operator
   guidance stays tied to measured artifacts instead of heuristics.
