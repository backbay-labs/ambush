## Cross-Phase Integration

The milestone contract is coherent end to end:

- Phase 208 established runtime-owned per-agent panic isolation so one crashing
  agent no longer unwinds the shared dispatcher or process boundary.
- Phase 209 turned repeated boundary failures into restart of only the affected
  agent, preserving healthy peers and visible health state.
- Phase 210 lifted those isolated failure signals into one explicit runtime
  degradation ladder with shared capabilities, triggers, and operator-facing
  status output.
- Phase 211 proved that the shipped degradation ladder enters the expected
  bounded states under substrate outage, replay-store write failure, and
  heap-pressure drain scenarios.

## E2E Flows Verified

1. A panicking agent now degrades independently instead of terminating the
   runtime process.
2. Persistent failed health now rebuilds only the affected agent through a
   dispatcher-owned restart factory.
3. The runtime now exposes one explicit degradation report on `/readyz`,
   `/healthz`, `swarmctl status`, and `/v2/api/runtime/status` instead of
   scattering implicit readiness checks.
4. Repo-owned transition proof now verifies NATS-down to `detect_only`,
   replay-store write-path failure to `read_only`, and heap pressure to
   `emergency_drain`.
