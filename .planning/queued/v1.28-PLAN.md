# Queued Milestone: v1.28 Durable Substrate And Multi-Instance Coordination

**Status:** Queued (activates after v1.27 completes)
**Created:** 2026-04-05

## Goal

Replace in-memory pheromone substrate with durable NATS JetStream backend, enable multiple swarm-detect instances to share pheromone state, and clean up legacy artifacts.

## Requirements

- **SUB-01**: NATS JetStream pheromone substrate backend persists deposits across restarts
- **SUB-02**: Multiple swarm-detect instances contribute deposits to shared substrate with correct concentration aggregation
- **SUB-03**: min_sources_for_escalation enforcement works correctly across multiple instances
- **CLEAN-01**: swarm-bridge (dead PyO3 shim) and kernel/ Python stubs are removed or archived

## Proposed Phase Structure

Starting from phase 86 (v1.27 ends at 85).

### Phase 86: NATS JetStream Pheromone Backend
**Goal**: Pheromone deposits survive restarts and are queryable from any connected instance
**Requirements**: SUB-01
**Success Criteria**:
1. PheromoneSubstrate trait has a JetStream implementation that persists deposits to NATS
2. Deposits survive process restart and are queryable on reconnection
3. Exponential decay and evaporation GC work correctly with durable deposits
4. ConfiguredPheromoneSubstrate can select JetStream backend via config

### Phase 87: Multi-Instance Coordination And Cleanup
**Goal**: Multiple detection instances share pheromone state and legacy code is removed
**Requirements**: SUB-02, SUB-03, CLEAN-01
**Success Criteria**:
1. Two swarm-detect instances depositing to shared NATS substrate see each other's deposits in concentration queries
2. min_sources_for_escalation correctly counts distinct source instances (not just distinct events)
3. Escalation thresholds fire only when enough independent sources contribute
4. swarm-bridge crate is removed from workspace
5. kernel/ directory is archived or removed
6. PORTING-TRACKER.md is updated to reflect all completed work

## Dependencies

- Phase 86 depends on v1.27 (deployment infrastructure provides NATS sidecar)
- Phase 87 depends on Phase 86 (multi-instance needs JetStream backend)
- async-nats crate needs to be added to workspace dependencies
