## Cross-Phase Integration

The milestone contract is coherent end to end:

- Phase 216 replaced the older fixed signal-count confidence arithmetic with
  learned per-scope online novelty distributions that survive restart through
  the shared behavioral baseline seam.
- Phase 217 turned that learned state into explicit support-weighted z-score
  evidence so operators can inspect why one event scored as anomalous.
- Phase 218 widened the same detector and baseline seam across the shipped
  network, DNS, authentication, registry, file, and process-memory telemetry
  families instead of keeping the improvement process-start only.
- Phase 219 checked in a repeatable labeled benchmark that measures the shipped
  widened detector and demonstrates the required false-positive reduction
  without catch-rate loss against a bounded legacy control.

## E2E Flows Verified

1. Behavioral learning now persists restart-safe novelty distributions instead
   of relying on the older fixed arithmetic formula.
2. Behavioral findings now expose explicit `deviation_scoring` evidence with
   z-score-derived confidence instead of opaque confidence bumps.
3. The widened detector now evaluates all shipped non-process telemetry
   families through the same bounded baseline and evidence contract.
4. The repo-owned behavioral anomaly benchmark now runs against labeled
   telemetry, records the measured quality result, and preserves that output in
   a checked-in artifact for later comparison.
